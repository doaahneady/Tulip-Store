## How to Access IT Dashboard

**Step 1:** Login
- Use IT Supervisor or IT Crew credentials

**Step 2:** Open User Menu
- Click on your name in the top navbar

**Step 3:** Click Dashboard Link
- IT Supervisor sees: "لوحة IT Supervisor"
- IT Crew sees: "لوحة IT Crew"

**Step 4:** View Dashboard
- Full analytics and statistics
- Charts and tables
- Real-time data

## Differences Between Dashboards

### Admin Dashboard:
- Full control
- Can edit/delete
- User management
- Settings access

### IT Dashboards:
- View-only
- Analytics and reports
- No edit/delete
- No user management
- Monitor performance
