## 🎯 How to Use

### Access Map Dashboard:
1. Login as supervisor
2. Click user menu (top right)
3. Click "لوحة مشرف التوصيل"
4. See real-time map with drivers

### Manage Drivers:
1. From map dashboard
2. Click "👥 إدارة السائقين" button (green, in header)
3. View/Add/Edit/Delete drivers
4. Click "← العودة للخريطة" to go back

### Add New Driver:
1. Go to driver management page
2. Click "إضافة سائق جديد"
3. Fill in form
4. Click "حفظ"

### Edit Driver:
1. Find driver in table
2. Click edit button (✏️)
3. Update information
4. Click "حفظ"

### Delete Driver:
1. Find driver in table
2. Click delete button (🗑️)
3. Confirm deletion
